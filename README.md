# VIARUM — Premium marketing website

Official standalone marketing website concept for `https://viarumapp.github.io/`.

## Design

- Premium black, gold and white theme based on the real VIARUM iPhone interface.
- Uses user-supplied authentic VIARUM road symbol and screenshots rather than invented app interface screenshots.
- Responsive desktop and mobile layouts, with support page and social metadata.
- No paid dependencies, frameworks, or backend services needed.

## Deployment

Copy the files (including the `assets/` folder) to the root of the public `viarumapp/viarumapp.github.io` repository. In GitHub repo **Settings → Pages → Build and deployment**, select **Deploy from a branch → main → /(root)**. Verify the live site. The website is separate from the private Rork/Supabase app repository.

## Pre-launch reminders

- App Store direct-download link deliberately not added while the public listing is unavailable. Replace social/launch CTA with actual App Store URL after launch.
- The site includes a support page but does not replace the need to verify an accurate public privacy-policy URL in App Store Connect.
- App screenshots are provided as visual references. Review privacy, licensing, real feature availability and public marketing statements before publishing.
- No fake ratings, review counts, users or live provider availability are shown.
